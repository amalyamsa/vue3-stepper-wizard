# vue3-stepper-wizard

A lightweight, headless, and customizable multi-step form plugin for Vue 3.

## Features

- ✅ Headless API
- ✅ TypeScript support
- ✅ Validation agnostic
- ✅ Dynamic steps
- ✅ Optional steps
- ✅ Custom navigation
- ✅ Tiny bundle size
